给iPhone添加配置文件强制使用加密DNS

2026-10-14 20:44≈ 212字≈ 1分钟

一、为什么要用加密DNS

传统 DNS 查询通常没有加密，运营商或网络中的其他环节可能通过 DNS 劫持、篡改解析结果，将用户引导至其他 IP 地址，甚至影响用户对目标网站的正常访问。

即使网站使用 HTTPS，DNS 查询仍可能暴露访问的域名，也可能在连接建立前遭到干预。更讽刺的是，HTTPS 证书体系本身也曾经出现过与中国相关机构有关的信任危机。2015 年，CNNIC （中国互联网络信息中心）未经授权签发了覆盖 Google 域名的证书，随后遭到主流浏览器取消信任，2016 年起，另一家中国证书机构WoSign 及其关联机构 StartCom 又因未经授权签发证书、证书签发日期回填等问题，被 Google Chrome 和 Mozilla Firefox 逐步取消信任。

我看他们现在的信用度，估计在大街上扫个充电宝都扫不出来了。所以，当我们面对 DNS 劫持、解析结果被篡改等风险时，使用 DoH 加密 DNS 是一种合理的防护措施。毕竟，不能因为某个东西声称自己值得信任，就放弃对技术风险的防范。

在家里就比较容易实现，无论是在路由器上还是Nas上都可以通过DNS服务器来做DoH轮询，比如把阿里云和Cloudflare的公共加密DNS做轮询，然后路由器DNS下发直接指向家里的DNS服务器就可以了。

但是手机上就比较麻烦，Wifi你当然可以指定DNS服务器，但是只能配置传统地址，比如阿里的223.5.5.5，可是加密地址https://dns.alidns.com/dns-query就没办法配置了。

还有就是iPhone到现在位置，窝蜂网络是没办法指定DNS的，可以通过代理APP去做DNS的复写，但是那种方式吧，感觉有些不优雅，而且也只能改变部分域名，还是希望能做到系统级别的DNS指定。

二、配置文件的作用

按照苹果官方支持的 DNS 配置机制，可以通过自己写一个配置文件来声明要求指定用哪一个DNS服务器。按照官方声明的格式写完之后，直接安装即可，不需要签名、也不需要越狱、更不需要打包，就很简单，只不过自己写的文件会有红字的风险提醒，这倒无所谓了。

在国内用就配置阿里的 DoH 服务地址，我懒得自己去查标准格式，直接扔给chatGPT让它帮我写的，主要就是把阿里的 DoH 服务地址https://dns.alidns.com/dns-query经过 Base64 编码写进去就好了，具体其实也不用看。如果想用可以直接用，如果担心的话就直接让大模型给你写一个可以改DNS的iOS配置文件，要求就是指定DoH服务地址，还有就是iOS27之后，旧版本的NetworkDNSSettings字段停用了，要用com.apple.configuration.network.dns-settings，跟大模型说清楚就好了。

三、还有需要声明的是

  • 它不是 VPN：它只配置加密 DNS，不会自动把所有网络流量转入隧道。

  • 它不是代理配置：它没有配置代理节点、路由规则或分流规则。

  • 它不是根证书：它没有安装自定义 CA 证书。

  • 它不是 MDM 设备管理注册：文件中没有要求把设备注册到组织的 MDM服务。

  • 它不能翻墙：DoH 只保护 DNS查询传输，不能保证目标网站可访问，也不能替代代理工具。

  • 它不保证去广告：去广告可能要配合ADGuard。

四、如何撤销

如果后续发现网络异常，或者想恢复原来的 DNS 行为，可以在 iPhone的设置中找到已安装的描述文件并移除。移除后，DNS行为会回到系统和当前网络、代理工具等配置共同决定的状态。
